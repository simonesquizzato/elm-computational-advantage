# elm-computational-advantage
Progetto realizzato nell'ambito della Tesi Magistrale in Analisi delle Serie Storiche che mira a calcolare il vantaggio computazionale derivante dall'utilizzo delle reti neurali ELM rispetto alle reti neurali artificiali feedforward classiche.

Il file Burden_computazionale_elm_nar.R contiene il codice R per la stima dei modelli ELM (funzione addestra_elm), dei modelli per reti neurali classiche (con l'ausilio della libreria nnet) e la stima del vantaggio computazionale a parità di topologia delle reti e a parità delle performance computazionali sul test set.

Nei file Abstract_Tesi_Simone_Squizzato.pdf e Tesi_Simone_Squizzato.pdf contengono, rispettivamente, l'Abstract e la Tesi relativi al progetto sviluppato contenenti ulteriori precisazioni sulla metodologia e sui risultati raggiunti.
